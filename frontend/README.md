# Doctype.io Frontend

React + TypeScript UI for Doctype.io. See the [root README](../README.md) for setup, environment variables, and deployment.

| Command         | Description |
|-----------------|-------------|
| `npm start`     | Start the dev server at http://localhost:3000 |
| `npm run build` | Build for production into `build/` |
| `npm test`      | Run tests in watch mode |
